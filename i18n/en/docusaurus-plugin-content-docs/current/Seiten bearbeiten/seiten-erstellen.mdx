# Creating Pages

import ImageAside from '@site/src/components/ImageAside';

Departments (*Referate*), service units (*Servicebetriebe*), and the StuPa each have
their own pages on the website, which they manage themselves. If you need a **new** page,
create it in the admin area.

:::caution Coordinate first
Every new page and every new menu item makes the website larger. Coordinate any new page
with the Speakers (*Sprecher\*innen*) and the webmaster team beforehand. In most cases,
the topic fits better as a section on an existing page—which is almost always the better
choice.
:::

## Creating a page

1. Go to **Pages → Add New Page**.
2. Enter a **Title**. It becomes the H1 heading of the page.
3. In the right sidebar under **Page Attributes**, choose the **Parent** page. It
   determines the URL path: a page under "EliStu" inherits `…/elistu/`.
4. Write and structure the content—see [Page Structure & Layout](./seiten-aufbau.mdx)
   and [Building Blocks (Templates)](./bausteine.mdx).
5. Check **Preview**, then click **Publish**.

<ImageAside src="/img/guide-gwyneth-en/seite-erstellen.png" third alt="Page Attributes in the sidebar showing the Parent page selector">
<strong>Page Attributes</strong> determine where the page lives in the hierarchy. The URL path is
derived from the parent page.
</ImageAside>

:::info No sidebars anymore
The old "Sidebars" tab for picking a sidebar no longer exists. Every page is rendered
full-width.
:::

## Language

Pages are language-specific. A German page is a separate entry alongside its English
counterpart, and both are **linked** via Polylang. Without that link, the language
switcher will not appear on the page.

How to create the English version is explained in
[Editing Translations](../uebersetzungen-bearbeiten.mdx).

## Adding the page to the menu

A published page is reachable via its URL, but not yet in the menu. Sometimes that is
intentional; most of the time it is not.

1. Go to **Appearance → Menus**.
2. Select the **`Hauptmenü (Top)`** menu at the top (click **Select** if needed).
3. On the left under **Pages**, check the new page and click **Add to Menu**.
4. Drag the entry to the right place in the menu structure.
5. Click **Save Menu**.

Then do the same in **`Hauptmenü (Top) - Englisch`**. If the entry is missing there, the
page will be missing on the English website.

:::warning Warning
How a menu item looks inside the mega menu—panel, group, subtitle—is controlled by the
webmaster team in the **Max Mega Menu** settings. Submit your request there instead of
experimenting with the menu directly. Details are in
[Menu & Mega Menu](../menue-und-megamenue.mdx).
:::

## When a page is no longer needed

Do not delete it—ask the webmaster team first. Deleted pages leave behind broken links
and stale redirects; usually a redirect is set up instead.
