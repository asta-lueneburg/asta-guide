# Events

import Screenshot from '@site/src/components/Screenshot';

Events on the new website are managed through **Posts** in the **Events**
(*Veranstaltungen*) category. There is no separate calendar plugin with custom event
fields anymore—the earlier instructions for "The Events Calendar" are outdated.

## Where events appear

- On the **homepage** in the *Next Events* list: the five most recent posts in the
  category.
- In the **category archive**, which is linked from the menu.
- In the **News overview**, depending on how the post lists are filtered.

## Creating an event

1. Go to **Posts → Add Post**.
2. Title: short and specific, e.g., "Talk on …" or "Event Calendar from 21.07.2025".
3. In the right sidebar under **Categories**, check **Events** (or **Veranstaltungen**
   for German posts)—and no other category, especially never **Uncategorized**.
4. Set a **Featured image**—it is shown in the event listings.
5. Write the post body just like any other post. For longer announcements, follow the
   same guidelines as in [Creating Posts](./beitraege-erstellen.mdx).
6. Click **Publish**.

:::caution Important
The date badge shown in the event list comes from the post's **publish date** (displayed
e.g. as "16 JAN"), not from a separate event-date field. Therefore, only publish the post
when that date fits—or adjust the publish date under **Publish** (*Status*) in the
sidebar.
:::

## How an event appears in the list

In the homepage list, each event shows only a **date badge** (day and month) next to the
title—no excerpt and no body text. The title therefore needs to speak for itself:
"Lecture: Antisemitism in Schools" works; "Lecture" alone does not.

## Weekly event calendar

For the weekly overview, stick to the established pattern: one post per week titled
"Event Calendar from DD.MM.YYYY" (*Veranstaltungskalender ab TT.MM.JJJJ*). Put this post
in the **Events** / **Veranstaltungen** category as well so it appears automatically in
the homepage list.

## English version

For the English website, assign the post to the **Events** category. Only publish the
English version once the event is completely translated; otherwise it will not appear in
the English listing. For how to create translations, see
[Editing Translations](./uebersetzungen-bearbeiten.mdx).
