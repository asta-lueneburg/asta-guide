# Semester Ticket Refund

import Screenshot from '@site/src/components/Screenshot';

Semester ticket refunds are **not** processed through a website form, but via a dedicated
email address. This page explains what is published on the website and who handles what.

## The page on the website

| Language | URL |
|---|---|
| German | [asta-lueneburg.de/service/ruckerstattung/](https://asta-lueneburg.de/service/ruckerstattung/) |
| English | [asta-lueneburg.de/en/service/semesterticket-refunds/](https://asta-lueneburg.de/en/service/semesterticket-refunds/) |

The page is linked in the menu under **Services → Semesterticket Refunds**
(*Semesterticket-Rückerstattung*) and contains:

- instructions on where to send applications,
- **hardship cases** (*Härtefälle*) and who is eligible to apply,
- **refund deadlines**,
- **downloads** required for the application.

The responsible department owns the content; text updates are applied by the webmaster on
request so that both language versions stay in sync.

:::caution Current status (page as of April 9, 2026)
The page states explicitly: **Applications only via email to semtix@asta-lueneburg.de.**
Do not accept applications through other channels and do not publish any other email
addresses.
:::

## The former 9-Euro-Ticket dashboard

The previous edition of this guide described an admin dashboard at
`9-euro.asta-lueneburg.de/admin` for adding eligible students, recording refunds, and
generating SEPA exports.

**That tool is no longer reachable**—the hostname no longer resolves. Its instructions
have therefore been removed. Anyone who needs to know how refunds are processed today
should contact the webmaster; access is not granted via the website.

:::info For editors
There is **no** online application form on the website for refunds. Adding a form to a
page does not replace the email workflow. Receiving applications by email is the intended
process.
:::

## Data protection

Applications contain matriculation numbers, postal addresses, and bank details. They may
only be handled by authorized staff, must not be forwarded, and must not be discussed in
group chats. Transfer exports contain personal data and must never be shared.
