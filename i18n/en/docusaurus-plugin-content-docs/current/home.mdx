# How to AStA Website

import Screenshot from '@site/src/components/Screenshot';

**Welcome to the guide for the AStA website!**

> Last updated: November 23, 2026 (Ezra)

Since the relaunch, the website has been running on the **Gwyneth** theme. After a lot of
work, this closed major security gaps. Accessibility by design also closes major gaps that
had been a goal for five years, including screen navigation, screen-reader optimization,
keyboard navigation, and much more.

The menu was completely redesigned as well, along with mobile optimization. In addition,
new integrations improve visibility and mobilization potential: department plenary times are
visible directly on the homepage, and Telegram info channels and Instagram channels can be
displayed directly on the website. Students do not need Instagram to view posts, and no data
is sent to Meta.

The website is the AStA's central, permanent home: everything published here can be found,
linked, and cited.

This guide is aimed at everyone who maintains content: departments (*Referate*), service
units (*Servicebetriebe*), project leads, and the StuPa.

## What changed with the relaunch

| Before | Now |
|---|---|
| Pages had their own **sidebar** with widgets | Every page is a **full-width block template**. There are no sidebars or widgets anymore |
| Content was assembled freely block by block | For recurring layouts, there are **ready-made building blocks (patterns)** |
| The **Excerpt** was just a summary | The Excerpt is now also the **meta description** for search engines and social media previews |
| Missing alt text went unnoticed | The editor **flags missing alt text** while editing |
| The menu was a flat list of links | The menu has **five panels** with groups and dedicated actions |
| There was no color scheme | The website supports **Light and Dark mode**, both built from the same color palette |

Not every area of the website is accessible to everyone. That is intentional: it prevents
anyone from accidentally changing settings that affect the entire website. Where a chapter
requires special permissions, this is noted in the text.
:::
