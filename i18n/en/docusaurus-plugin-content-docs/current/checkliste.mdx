# Pre-Publish Checklist

This checklist applies to both posts and pages. It is short enough to actually use every
time.

## Content

- [ ] **Title** is specific and free of clickbait
- [ ] **Excerpt** is filled in, 120–155 characters, and reads like a full sentence
- [ ] **One** category selected, "Uncategorized" (*Unkategorisiert*) not checked
- [ ] **Featured image** is set
- [ ] No placeholders: "text coming soon", "Lorem ipsum", or sample text from building
  blocks
- [ ] No duplicate sources of truth: existing information is **linked** instead of copied

## Structure

- [ ] The page title is **not** repeated inside the body content
- [ ] Headings start at **H2**, with subsections at **H3**
- [ ] No pasted font sizes or hex colors (custom font sizes, drop caps, and custom color
  pickers are disabled in the editor—use only the AStA palette)
- [ ] Sections are structured clearly: H2 for main sections, H3 underneath
- [ ] On department pages: **Featured image**, **Badge (Startseite)** (DE), and
  **Übersichtskarte (Referat)** (fill in at least 2 content fields so the card appears)
  checked — see [Maintaining Department Pages](./Seiten%20bearbeiten/referat-seite.mdx)

## Images

- [ ] Every informative image has **alternative text** (the editor warns if it is missing)
- [ ] Decorative images have **empty** alternative text
- [ ] Filenames are descriptive (`referat-archipel-logo.jpg`)
- [ ] Photos were resized before uploading

## Links

- [ ] All links work
- [ ] Link text states where the link leads ("Apply for Semesterticket", not "click here")
- [ ] External links open in a new tab only when intended

## Languages and menus

- [ ] English version created — or intentionally deferred and noted
- [ ] For a new page: added to **both** main menus
- [ ] Language switcher is visible on the page (Polylang link exists)

## Before clicking "Publish"

- [ ] **Preview** checked on both desktop and phone
- [ ] No clipped words or overlapping elements
- [ ] Checked in **dark mode**
- [ ] For events: date and time are accurate
